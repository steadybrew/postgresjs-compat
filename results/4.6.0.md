# @steadybrew/postgresjs 4.6.0

Run on 2026-10-22 with `@steadybrew/postgresjs-migrate` 0.1.1 and PostgreSQL 17, except where a library starts its own ([workflow run](https://github.com/steadybrew/postgresjs-compat/actions/runs/39859807245)).

Each library's own tests run on its pinned checkout, in separate jobs with fresh installs:

- **3.4.9**: `@steadybrew/postgresjs-migrate --switch`, then the dependency set to `postgres` 3.4.9. The switch also removes any `postgres` patch the fork already contains, so this is plain 3.4.9. Libraries: drizzle-kit-push, drizzle-orm, kysely-postgres-js, paperclip.
- **Fork**: the same switch, with `@steadybrew/postgresjs` 4.6.0. Libraries: drizzle-kit-push, drizzle-orm, kysely-postgres-js, paperclip, paperclip-app.
- **As published**: the checkout without the switch, for libraries that ship their own patched `postgres`. Libraries: paperclip, paperclip-app.

A regression is a test or step that passes with 3.4.9 or as published, and fails with the fork. "Passing on both", "Fixed by the fork" and "Failing on both" compare the fork with 3.4.9, or with the published checkout for a library that has no 3.4.9 run.
