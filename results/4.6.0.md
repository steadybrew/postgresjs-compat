# @steadybrew/postgresjs 4.6.0

Run on 2026-10-22 with `@steadybrew/postgresjs-migrate` 0.1.1 and PostgreSQL 17, except where a library starts its own ([workflow run](https://github.com/steadybrew/postgresjs-compat/actions/runs/39804655325)).

Each library's own tests run twice on the same checkout after `--switch`: once with `postgres` 3.4.9 and once with `@steadybrew/postgresjs` 4.6.0. A library that ships its own patched `postgres` also runs once on its unchanged checkout. A regression is a test or step that passes with 3.4.9, or on the unchanged checkout, and fails with the fork.
