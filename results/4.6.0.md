# @steadybrew/postgresjs 4.6.0

Run on 2026-10-22 with `@steadybrew/postgresjs-migrate` 0.1.1 and PostgreSQL 17, except where a library starts its own ([workflow run](https://github.com/steadybrew/postgresjs-compat/actions/runs/39859807245)).

Each library's tests run in up to three ways, each in its own job with a fresh install:

- **3.4.9**: plain `postgres` 3.4.9. The switch tool removes any `postgres` patch the library carries, so this run has none.
- **As published**: the library exactly as published, with its own patched `postgres`. Only for libraries that ship one.
- **Fork**: `@steadybrew/postgresjs` 4.6.0, with any `postgres` patch removed.

A regression is a test that passes with 3.4.9 or as published, and fails with the fork. The other counts compare the fork with 3.4.9, or with the published library when there is no 3.4.9 run.
