# @steadybrew/postgresjs 4.8.0

Run on 2026-11-04 with `@steadybrew/postgresjs-migrate` 0.2.0 and PostgreSQL 17, except where a library starts its own ([workflow run](https://github.com/steadybrew/postgresjs-compat/actions/runs/41901324400)).

Each library's tests run in up to 5 ways, each in its own job with a fresh install:

- **3.4.9**: plain `postgres` 3.4.9. The switch tool removes any `postgres` patch the library carries, so this run has none.
- **As published**: the library exactly as published, with its own patched `postgres`. Only for libraries that ship one.
- **Fork**: `@steadybrew/postgresjs` 4.8.0, with any `postgres` patch removed.
- **Upstream 4.0.0**: `postgres@4.0.0` in place of the fork, with the same switch and patch removal.
- **Upstream c32cf5a**: [porsager/postgres@c32cf5a](https://github.com/porsager/postgres/tree/c32cf5ac852f4f02150d3cc03f34621cc86a03b7) in place of the fork, with the same switch and patch removal.

A regression is a test that passes with 3.4.9 or as published, and fails with the fork or upstream run it is counted for. The other counts compare that run with 3.4.9, or with the published library when there is no 3.4.9 run.
